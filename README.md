# ClinicFlow Pro

Sistema SaaS de gestão para clínicas de fisioterapia e saúde: agenda, pacientes, prontuário,
avaliações, evoluções, planos terapêuticos, documentos, assinatura eletrônica, WhatsApp,
financeiro, relatórios e auditoria.

> **Status:** front-end completo com dados fictícios. O back-end (banco de dados, login real e
> integrações) ainda será construído.

## Rodando localmente

Requer [Node.js](https://nodejs.org) 20.19 ou superior.

```sh
npm install
npm run dev
```

Abra http://localhost:8080.
